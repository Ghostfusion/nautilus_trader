Sector Regime Engine

A regime-gated sector allocation tool implementing strategies/sector_rotation_strategies.md. It measures two independent axes, gates every directional overlay on statistical significance, and attributes the result by comparison type. Nothing here predicts sector leadership.

11. Held-out window

The regime is decided on the observation window only and then frozen. Held-out results are hidden until revealed, which is the point of pre-registration.

12. Instrument validation

The engine is a measuring instrument, so it is measured: the same data is generated with a known regime and the classifier is scored against it, across several seeds and all three worlds.

Every number shown is produced by src/engine.js, which is covered by tests/engine.test.mjs. No forecasting library, no network calls, no build dependencies beyond the bundler.
